# Contributing

Feedback is welcome.

## Good Contributions
- Suggest a public PR that may benefit from a short risk brief.
- Point out where a brief is unclear or too noisy.
- Explain whether a brief would help you review a PR.
- Ask for clarification through Issues.

## Rules
- Be respectful.
- Do not attack project maintainers, contributors, companies, or individuals.
- Do not harass or notify target projects unnecessarily.
- Do not submit sensitive security issues here.
- Do not include private or confidential information.
- Do not use this repository to pressure maintainers.

## Security-Sensitive Topics
This project does not handle sensitive security disclosures.

If you find a security issue in a project, follow that project's official security policy.
