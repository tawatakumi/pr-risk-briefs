# PR Risk Briefs

Short, human-readable risk briefs for public pull requests before review.

## Purpose
This repository is an experiment using public GitHub pull requests to briefly organize:

- What changed.
- Risks that may be easy to miss.
- Impact areas.
- Test focus.
- Questions reviewers may want to consider.

The goal is to test whether short, low-noise PR risk briefs are useful before any product implementation.

## What This Is
- Manual Risk Brief validation using public PRs.
- A review-understanding aid before PR review.
- Value validation before implementation.
- A low-noise review focus experiment.

## What This Is Not
- Not a GitHub Action.
- Not an AI code review product.
- Not a marketplace product.
- Not an automated review bot.
- Not an official review for any target repository.
- Not affiliated with Supabase, Cal.com, or other analyzed projects.
